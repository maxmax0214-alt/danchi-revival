# 団地再生ものがたり - Web Prototype

古い団地を改修し、住民・商店・仕事場・公園を増やしていく、コミカルなドット絵経営ゲームの最小プロトタイプです。

## 特徴

- Phaser 3によるブラウザ向け2Dゲーム
- 画像ファイル不要。初期ドット絵はコードから生成
- 住民が団地内を歩く
- 施設を選んでマップへ建設
- 月次収益、人口、団地ランク
- 施設の組み合わせによる「団地コンボ」
- 短いコミカルイベント

## 起動方法

ローカルサーバーで開いてください。

```bash
python3 -m http.server 8000
```

ブラウザで `http://localhost:8000` を開きます。

Node.jsがある場合は、次でも構いません。

```bash
npx serve .
```

## GitHub Pages

リポジトリ直下へ配置し、GitHub Pagesを `main` ブランチのルートから公開すると、そのまま遊べます。

## 次の実装候補

1. 住民の名前・職業・夢
2. 住宅への入居と退去
3. ベンチャー誕生条件
4. 施設ごとの利用行動
5. セーブ／ロード
6. タイルマップとスプライトシートへの移行
7. スマートフォン向け操作調整

## アート方針

特定作品の画像、UI、キャラクターを複製せず、以下の要素だけを参考にしたオリジナル表現を採用します。

- 16〜32px単位の読みやすいドット絵
- 2頭身の住民
- 小さな動作で性格を表現
- 温かい色調
- 深刻な社会課題を短いユーモアへ変換
